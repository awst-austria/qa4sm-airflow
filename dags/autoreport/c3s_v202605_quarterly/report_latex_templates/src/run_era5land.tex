\subsection{Validation settings} \label{ssec:era5_settings}

\noindent The \ac{C3S} SM COMBINED, ACTIVE and PASSIVE products were compared against ERA5-Land (\detokenize{$<ContentVars['NetcdfMetaVars']['val_dc_version_pretty_name0']>$}, top soil layer 0--7\,cm, Chapter \ref{ssec:era5land}) in a second validation run, with the following settings (full list: results page linked in Table \ref{tab:val_run_list}):

\begin{itemize}
    \item Spatial reference: \textbf{\detokenize{$<ContentVars['ConfigVars']['spatial_reference']>$}}; temporal reference: \textbf{\detokenize{$<ContentVars['ConfigVars']['temporal_reference']>$}} (matching window: \detokenize{$<ContentVars['ConfigVars']['temporal_matching']>$} hour(s))
    \item Scaling: \textbf{\detokenize{$<ContentVars['ConfigVars']['scaling_method'].replace('_', ' ')>$}} (scaling reference: \textbf{\detokenize{$<ContentVars['ConfigVars']['scaling_reference']>$}}); metrics \detokenize{$<'\\textbf{are}' if ContentVars['ConfigVars']['anomalies_method']!='none' else '\\textbf{are not}'>$} based on anomalies.
\end{itemize}

\noindent As ERA5-Land is spatially and temporally complete, the results cover all land areas where the products provide valid retrievals, and changes in the number of validated locations reflect the availability of the satellite data (Chapter \ref{ssec:tracking_availability}).
ERA5-Land is model-based and has its own errors: the metrics describe the agreement between the datasets rather than the accuracy of the products, so the \ac{C3S} accuracy requirement is not applied.
As in the \ac{ISMN} run, the products are scaled to the reference (\ac{ubRMSD} of all products in \unitsm{}) and only common time stamps of all datasets are used.
Results are computed on the \detokenize{$<ContentVars['NetcdfMetaVars']['val_resolution']>$}° ERA5-Land grid (nearest 0.25° product cell).

\subsection{Results} \label{ssec:era5_results}

\noindent The products were compared at \textbf{\detokenize{$<ContentVars['NetcdfVars']['n_gpis']>$}} ERA5-Land land grid points.
No metrics are computed where too few valid observations remain, mostly at frozen or snow-covered soils and where the products provide no retrievals (e.g.\ dense tropical forests).
Fig.\ \ref{fig:era5_status\runidx} shows the validation status and the number of common observations (n\_obs) per grid point.
As ERA5-Land is gap-free, n\_obs reflects the temporal availability of the satellite data (temporal reference: \ac{C3S} SM COMBINED); it is the same for all products.
Table \ref{tab:era5_summary} summarises Pearson's R and the \ac{ubRMSD} across all valid grid points, Fig.\ \ref{fig:era5_maps\runidx} shows their spatial patterns.
The tracking across reports is shown in Chapter \ref{ssec:tracking_era5}; further plots are available with the validation results \href{\detokenize{$<ContentVars['NetcdfMetaVars']['url']>$}}{online}.
