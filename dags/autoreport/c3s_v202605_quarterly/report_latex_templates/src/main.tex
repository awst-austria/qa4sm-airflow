    \section{Report summary} \label{sec:summary}

    \noindent This report validates the \cdsall{} (v202605) surface soil moisture records for \detokenize{$<ReportVars['Common']['interval_from']>$} to \detokenize{$<ReportVars['Common']['interval_to']>$} against \ac{ISMN} in situ measurements (0--10\,cm), using a single validation run with common sensors and time stamps for all products.
    Of the \detokenize{$<len([v for k, v in ReportVars.items() if k.startswith('Tracking ') and 'tracking' in v])>$} tracked metrics, \textbf{\detokenize{$<len([v for k, v in ReportVars.items() if k.startswith('Tracking ') and v.get('tracking', {}).get('tracking_status') == 'ok'])>$}} are within their expected range, \textbf{\detokenize{$<len([v for k, v in ReportVars.items() if k.startswith('Tracking ') and v.get('tracking', {}).get('tracking_status') == 'not ok'])>$}} are outside, and \textbf{\detokenize{$<len([v for k, v in ReportVars.items() if k.startswith('Tracking ') and v.get('tracking', {}).get('tracking_status') == 'none'])>$}} could not be classified (Table \ref{tab:val_run_list}, details in Chapter \ref{sec:tracking}).
