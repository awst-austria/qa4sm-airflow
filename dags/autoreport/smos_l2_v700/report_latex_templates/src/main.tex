    \noindent This report comprises validation results for SMOS L2 v700 satellite soil moisture against ERA5-Land reanalysis and ISMN in situ data.

    \vspace{5mm}

    \noindent \textbf{Overall Tracking Quality Indicator:} Chapter \ref{sec:tracking} tracks selected metrics between SMOS L2
    and reference data sets across reports in this series to detect unexpected changes in the SMOS L2 Soil Moisture data
    quality. Fig. \ref{fig:indicator} combines these results. A \textcolor{green}{green} light means that \textit{all}
    tracked metrics for this report were found to be within the expected thresholds, \textcolor{orange}{yellow} means that
    in some cases the target thresholds were not met, and \textcolor{red}{red} means that in \textit{all} cases performance metrics were
    outside the expected bounds.
    No color means that no tracking was performed.
    The report filename appendix (G, Y, R, N) also refers to this indicator.
